# 🚀 TaskFlow – Office Management System

**TaskFlow** is a web-based Office Management System designed to simplify project management, task tracking, team collaboration, and meeting scheduling through a clean and user-friendly interface.

## 🌐 Live Demo

👉 **[Visit TaskFlow – Live Website](https://task-flow-office-management-system.onrender.com/)**

## 📌 Project Overview

TaskFlow helps teams organize their daily office activities in one place. Users can manage projects, assign tasks, monitor progress, collaborate with team members, and schedule meetings efficiently.

## ✨ Features

- 🔐 User Registration and Login
- 📊 Interactive Dashboard
- 📁 Project Management
- ✅ Task Creation and Tracking
- 👥 Team Member Management
- 📅 Meeting Scheduling
- 🔄 Task Status and Priority Management
- 🎨 Clean and Responsive User Interface

## 🛠️ Technologies Used

**Frontend**
- React.js
- JavaScript
- HTML5
- CSS3
- Vite

**Backend**
- Node.js
- Express.js
- REST API
- JWT Authentication
- bcryptjs

**Database**
- SQLite

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/saiyogesh-1244/Task-flow-Office-Management-System.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Task-flow-Office-Management-System
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Build the project:

   ```bash
   npm run build
   ```
