# TaskFlow Office Suite

A Streamlit office management app with a refined navy, blue and gold interface inspired by the original TaskFlow React design.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Demo account: `demo@taskflow.local` / `taskflow123`

The app initializes a local SQLite database automatically. For persistent production use on Streamlit Community Cloud, connect a hosted database rather than relying on ephemeral local storage.
